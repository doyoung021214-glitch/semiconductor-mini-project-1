# semiconductor-mini-project-1

반도체 BSI와 생산지수 비교 — 미니프로젝트 1

## 프로젝트 목표

기업의 체감 경기를 보여주는 반도체 BSI 현황과 실제 생산 흐름을 같은 분기에서 비교했습니다. Python으로 공공데이터를 정제한 뒤 MariaDB에 적재하고, SQL로 월별 생산지수를 분기 평균으로 집계해 BSI와 연결했습니다.

## 업종 선정 이유

- **반도체**는 평소 관심이 많고 앞으로의 산업 흐름을 이해하는 데 중요하다고 생각해 중심 업종으로 골랐습니다.
- **디스플레이와 자동차**는 반도체를 부품으로 사용하는 업종입니다. 세 업종의 경기 흐름이 비슷한 시기에 움직이는지 후속 프로젝트에서 비교하기 위해 BSI 정제 대상에 포함했습니다. 이번 실제 생산지수 비교는 반도체를 대상으로 했습니다.
