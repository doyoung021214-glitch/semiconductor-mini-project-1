# semiconductor-mini-project-1

반도체 BSI와 생산지수 비교 — 미니프로젝트 1

## 프로젝트 목표

기업의 체감 경기를 보여주는 반도체 BSI 현황과 실제 생산 흐름을 같은 분기에서 비교했습니다. Python으로 공공데이터를 정제한 뒤 MariaDB에 적재하고, SQL로 월별 생산지수를 분기 평균으로 집계해 BSI와 연결했습니다.

## 업종 선정 이유

- **반도체**는 평소 관심이 많고 앞으로의 산업 흐름을 이해하는 데 중요하다고 생각해 중심 업종으로 골랐습니다.
- **디스플레이와 자동차**는 반도체를 부품으로 사용하는 업종입니다. 세 업종의 경기 흐름이 비슷한 시기에 움직이는지 후속 프로젝트에서 비교하기 위해 BSI 정제 대상에 포함했습니다. 이번 실제 생산지수 비교는 반도체를 대상으로 했습니다.

## 실행 순서

1. 원본 CSV 두 개를 노트북과 같은 폴더에 둡니다. 다운로드한 파일명이 다르면 노트북의 `pd.read_csv()`에 적힌 파일명을 맞춰주세요. [전처리 노트북](clean_data.ipynb)을 실행하면 업종별 BSI **168행**과 반도체 월별 생산지수 **90행**을 CSV로 저장합니다. 결측치·중복 여부를 확인하고, 생산지수의 잠정치는 별도 열에 표시했습니다.
2. MariaDB의 `semiconductor_course`에 BSI 정제본 `bsi_quarterly_notebook.csv`를 `bsi_quarterly`로, 생산지수 정제본 `production_monthly_notebook.csv`를 `production_monthly`로 가져옵니다. 날짜 열은 `DATE`, 지수 값은 숫자형으로 설정합니다.
3. [분기별 분석 SQL](mini_project_1.sql)에서 `USE`, `CREATE TABLE`, 첫 번째 집계 `SELECT`까지 차례로 실행합니다. 집계 결과를 CSV로 내보내고 `production_quarterly`로 가져옵니다.
4. `COUNT(*)`로 **분기별 생산지수 30행**을 확인합니다. 마지막 `SELECT`는 업종과 분기 시작일을 기준으로 BSI 현황을 연결하고, 직전 분기와 비교해 생산지수 변화율을 계산합니다.

## 확인한 결과

2019년 3분기부터 2026년 2분기까지 **28개 분기**를 비교했습니다. 예를 들어 **2023년 2분기**에는 반도체 BSI 현황이 **74**였고, 계절조정 생산지수는 직전 분기보다 **19.0% 증가**했습니다. 기업의 체감 경기와 생산 흐름이 엇갈릴 수 있음을 보여주는 사례입니다.
